第 13 章 · 标准化与参数化 g 算法

Hernán MA, Robins JM（2020）. Causal Inference: What If. Chapter 13. 本页为中文全文翻译，附译注。

这一章讲清楚怎么用标准化估计戒烟对体重增长的平均因果效应，用的还是上一章那份观察性数据集。标准化在第 2 章就露过面，但当时只把它当作一种非参数方法。现在我们要把模型和标准化一起用起来，这样才能对付协变量众多、处理不限于二值的高维问题。和上一章一样，我们也附上代码。在实际操作中，研究者面对观察性数据时，往往要在 IP 加权和标准化之间挑一个作为求效应估计的分析路径。两者建立在同样的可识别性条件上，只是建模假设不同。

13.1 作为 IP 加权替代的标准化

上一章我们用 IP 加权估计了戒烟 A（1：是，0：否）对体重增长 Y（以 kg 计）的平均因果效应。这一章改用标准化来估计同一个效应。分析依旧基于 NHEFS 数据：1629 名 25–74 岁的吸烟者，都有过基线访视，约十年后又有一次随访。其中 1566 人在随访时测了体重，因而未被删失（C = 0）。

我们把 E[Ya,c=0] 定义为：如果所有人都接受处理水平 a、并且没有任何人被删失，本会观测到的平均体重增长。戒烟的平均因果效应就写成 E[Ya=1,c=0] − E[Ya=0,c=0]，也就是"所有人戒烟且都未被删失"与"所有人都不戒烟且都未被删失"这两种情形下平均体重之差。

如表 12.1 所示，戒烟者（A = 1）与不戒烟者（A = 0）在体重增长预测因子的分布上确有差别。观察到的关联差 E[Y|A=1, C=0] − E[Y|A=0, C=0] = 2.5 预期会与因果差 E[Ya=1,c=0] − E[Ya=0,c=0] 不同。我们仍然假定：变量向量 L 足以调整混杂与选择偏倚，且 L 包含基线变量性别（0：男，1：女）、年龄（岁）、种族（0：白人，1：其他）、教育程度（5 类）、吸烟强度与吸烟年限（每日支数、吸烟年数）、日常生活中的体力活动（3 类）、休闲锻炼（3 类）以及体重（kg）。

和上一章一样，我们还假定 L 中用于调整 C 的那些成分不受 A 影响。否则就得改用第三部分介绍的那套更一般的做法。

调整 L 的一种办法是 IP 加权，它造出一个伪人群，使 L 中各变量的分布在处理组与未处理组中相同。在给定 L 的可交换性（exchangeability）与可阳性性（positivity）假设下，只需算出伪人群中的平均结局 E[Y|A = a, C = 0]，就估出了 E[Ya,c=0]。（若 A 是连续处理——与我们的例子相反——那还需要一个结构模型，才能在伪人群中估计 A 所有取值下的 E[Y|A, C = 0]。）

精细辨析 13.1　结构性可阳性性（structural positivity）

结构性可阳性性的缺失，会使 IP 加权无法在整个人群中识别平均因果效应。标准化同样需要可阳性性：当 Pr[A = a|L = l] = 0 而 Pr[L = l] ≠ 0 时，条件均值 E[Y|A = a, L = l] 无从定义。

不过，在依赖参数模型的前提下，可阳性性被违背的实际后果，对 IP 加权估计和标准化估计来说可能大不相同。做标准化时，只要愿意依赖参数外推，就可以对可阳性性的缺失睁一只眼闭一只眼：拟合一个 E[Y|A, L] 的模型，让它把结构性零所在的层平滑过去。这种平滑会给估计引入偏倚，于是估计值周围那个名义上的 95% 置信区间，覆盖真实效应的频率会低于 95%。还要注意，在结构性可阳性性这个情境下，建模的目的与平常不同：我们建模不是因为数据不够，而是因为想估计的东西即便有无穷多的数据也无法识别（因为存在结构性不可阳性）。这个区别很要紧。

一般来说，在可阳性性被违背或接近被违背的情况下，标准化所得处理效应的标准误会小于 IP 加权。但这并不意味着标准化就优于 IP 加权：偏倚上的差距可能把标准误上的差距盖过去。

第 2 章讨论过，IP 加权之外的另一个选择是标准化。在给定 L 变量的可交换性与可阳性性条件下，技术要点 2.3 证明了：在条件可交换性、可阳性性与一致性之下，处理组内的标准化平均等于所有人都接受处理时的平均值。推广到删失的情形也很简单：在证明与定义中把 A = a 换成 (A = a, C = 0) 就行。技术要点 4.1 描述了用标准化估计处理组平均因果效应的做法；只要在右边那个表达式里把 Pr[L = l] 换成 Pr[L = l|A = 1] 即可。

要算出"未删失的处理组"的标准化平均结局，得先算出混杂因素 L 每一层 l 内未删失处理者的平均结局，也就是每一层 l 上的条件均值 E[Y|A = 1, C = 0, L = l]。在戒烟这个例子里，就是要在由 L 中 9 个变量取值组合而成的（可能多达几百万个）层里，分别算出那些戒烟且未被删失者的平均体重增长 Y。

随后，"未删失的处理组"的标准化平均就是这些条件均值的加权平均，权重取各取值 l 在研究人群中的比例 Pr[L = l]。也就是说，人数最多的那一层，其条件均值在标准化平均中占的权重最大。"未删失的未处理组"的标准化平均算法相同，只需把条件事件中的 A = 1 换成 A = 0。更紧凑的写法是，未删失且接受处理水平 a 者的标准化平均为

∑l E[Y|A = a, C = 0, L = l] × Pr[L = l]

像我们这个例子，L 中有些变量是连续的，此时要把 Pr[L = l] 换成概率密度函数（pdf）fL[l]，上面那个求和也就变成了积分。

接下来两节讲怎么估计结局 Y 的条件均值，以及混杂因素 L 的分布——这正是估计标准化平均所需的两类量。

13.2 通过建模估计均值结局

理想情况下，我们希望非参数地估计出条件均值集合 E[Y|A = 1, C = 0, L = l]：在 L 各变量取值的各种组合所定义的分层内，分别算出未删失处理者的平均结局。第 2.3 节做的正是这件事，那一节所需的全部信息都来自表 2.2。

但在我们眼下这个例子里，非参数地估计 E[Y|A = 1, C = 0, L = l] 根本不可能：数据维度很高，混杂因素众多，其中若干还有多个水平。处理组只有 403 人，却要散布到几百万个层里，我们拿不到任何有意义的、非参数的层别平均结局估计。未删失未处理组的条件均值 E[Y|A = 0, C = 0, L = l] 同理。只能求助于建模。

为了在 L 定义的每一层里参数化地估计 E[Y|A = a, C = 0, L = l]，我们对平均体重增长拟合一个线性回归模型，把处理 A 和 L 中全部 9 个混杂因素都作为协变量放进去。对年龄、体重、吸烟强度、吸烟年限这几个（准）连续协变量，我们用了线性项和二次项。也就是说，模型把 E[Y|A = a, C = 0, L = l] 的可能取值限制住，要求连续协变量与平均结局之间的条件关系能由一条抛物线表示。我们还加进了戒烟 A 与吸烟强度之间的乘积项：模型强加了一个限制，即每个协变量对均值的贡献都不依赖于别的协变量，只有戒烟 A 的贡献会随既往吸烟强度线性变化。

在这些参数化限制之下，我们对 A 与 L 的每一种取值组合都得到了一个估计值 Ê[Y|A = a, C = 0, L = l]，从而对研究人群中每一个未删失的处理者（A = 1, C = 0）和每一个未删失的未处理者（A = 0, C = 0）都得到了一个——共 403 名与 1163 人。举个例子：一位取值组合为{不戒烟、男性、白人、26 岁、大学肄业、每日 15 支、吸烟 12 年、锻炼量中等、日常活动量很大、体重 112 kg}的个体，我们估计他的平均体重增长为 0.34 kg（该个体的唯一标识号恰为 24770，有兴趣的读者可以去查他的预测值）。总体上，估计体重增长的均值为 2.6 kg，与观察到的体重增长均值相同；后者的取值范围是 −41.3 kg 到 48.5 kg。

一般来说，标准化平均体重增长写作 ∫ E[Y|A = a, C = 0, L = l] dFL(l)，其中 FL(·) 是 L 中各随机变量取值的联合累积分布函数（cdf）。像本章这样，当 L 是一组不受处理影响的基线协变量时，我们可以在 L 的观测取值上取平均，从而非参数地估计这个积分。记号上的这些麻烦可以先放一放：别忘了我们的目标是估计处理组（A = 1）与未处理组（A = 0）中 ∫ E[Y|A = a, C = 0, L = l]×Pr[L = l] 这个标准化平均。更正式地说，由于 L 中有些变量本质上是连续的、其分布无法用概率函数表示，标准化平均应该写成积分。无论采用哪种记号，上面我们已经为处理 A 与混杂因素 L 的一切取值算出了均值 E[Y|A = a, C = 0, L = l] 的估计值。

下一步，就是把这些均值标准化到混杂因素 L 在全部取值 l 上的分布。

13.3 把均值结局标准化到混杂因子的分布

标准化平均是条件均值 E[Y|A = a, C = 0, L = l] 的加权平均。当 L 中所有变量都是离散变量时，每个均值拿到的权重等于取值 L = l 的个体所占比例，即 Pr[L = l]。原则上，这些比例可以直接从数据里非参数地算出来：把 L = l 层里的个体数除以人群总数。第 2.3 节就是这么做的，那一节所需的全部信息都来自表 2.2。可在戒烟这个例子这种高维、混杂因素众多且不少还有多个水平的数据上，这个办法就笨重得没法用了。

译注

译注 1（"标准化"这个词的歧义，以及 g 算法的中文译名）：中文语境里的"标准化"至少有两个毫不相干的含义。一是统计学与医学统计中的标准化（standardization of data）：把变量换算成 z 分数，或用直接标化法按人口年龄构成把粗率调整成标准人口率——国内卫生统计年鉴里那一堆"标化死亡率"讲的是这个。二是本章讲的因果标准化：把各层内的处理组均值按混杂因素的分布重新加权平均，让处理组与非处理组在混杂因素上"长得一样"。二者数学形式相似，处理对象完全不同，翻译时只能用括号或上下文区分。

译注 2（g-formula 这个名字是怎么来的）：Robins（1986）当年是把标准化推广到时变处理和时变混杂因素的一般方法，命名为 g-computation algorithm formula——全称长到没人愿意念，于是文献里有了 g-formula、g-computation、GC 算法等写法。中文文献里"g 公式""g-计算""参数化 g 公式""参数化 g 算法"都出现过，本书统一用"g 算法"。要留神的是，g-computation 在英文里极易与 g-estimation（第 14 章的主题）混淆——两者是完全不同的方法，只差一个字母。检索英文文献时务必把两者分开查，否则会捞回一大片不相干的论文。

幸好，我们其实不需要估计 Pr[L = l]。我们只需要为研究中每个个体 i 的 Li 值算出 E[Y|A = a, C = 0, L = l]，然后求平均：(1/n) ∑i=1n Ê[Y|A = a, C = 0, Li]，其中 n 是研究中的个体数。这之所以成立，是因为加权平均 ∑l E[Y|A = a, C = 0, L = l] Pr[L = l] 也可以写成双重期望 E[E[Y|A = a, C = 0, L]]。

下面介绍一种简单的计算方法：在混杂因素众多时估计处理组（A = 1）与未处理组（A = 0）的标准化平均 ∑l E[Y|A = a, C = 0, L = l]×Pr[L = l]，而全程不必显式估计 Pr[L = l]。我们先把方法用在表 2.2 的数据上——那里没有删失，混杂因素 L 只有一个两水平变量，结局 Y 是二值的，因此均值 E[Y|A = a, C = 0, L = l] 就是发生结局的风险 Pr[Y = 1|A = a, L = l]——然后再用到带删失、多混杂因素的真实数据上。整个方法分四步：数据集扩展、结局建模、预测、按平均做标准化。

表 2.2 有 20 行，对应研究中的 20 个个体。现在我们新建一个数据集，把表 2.2 的数据复制三份。也就是说，分析数据集有 60 行，分成三个各 20 人的区块。第一块 20 行原样保留，与表 2.2 完全一致；第二、三块按边注所示修改。第二块中，把全部 20 人的 A 都设为 0（未处理）；第三块中，把全部 20 人的 A 都设为 1（处理）。第二、三块中，所有人的结局数据都被删去，即变量 Y 取缺失值。下文会用到：第二块用来估计未处理组的标准化平均，第三块用来估计处理组的标准化平均。

接下来用这个三区块数据集，对给定处理 A 和混杂因素 L 的平均结局拟合回归模型。我们加入乘积项 A × L 使模型饱和。注意，只有第一区块（真实数据）的行会参与模型参数的估计，因为第二、三块所有行的结局都是缺失的。

下一步，是把第一区块拟合得到的参数估计，用来预测第二、三区块所有行的结局值（也就是把 L 与 A 两列的取值同回归估计结合起来，为结局 Y 填补缺失值）。第二区块的预测结局值就是每一组 L 与 A = 0 取值组合对应的均值估计，第三区块的预测值则是 L 与 A = 1 各组合对应的均值估计。

最后，对第二区块所有预测值取平均。由于 60% 的行取 L = 1、40% 取 L = 0，这个平均会更多地给 L = 1 的行加权。也就是说，第二区块预测值的平均，恰好就是未处理组的标准化平均结局。要估计处理组的标准化平均结局，只需对第三区块所有预测值取平均。

译注

译注 3（经验分布 vs 总体分布：用谁的分母，谁就说话）：13.3 节这个"复制数据块再求平均"的技巧，是把 ∑l 换成 (1/n)∑i 的实现方式。它隐含了一个容易被忽略的选择：Pr[L = l] 用的是研究样本自身的经验分布，因此标准化平均被锚定在"本研究人群"上，而不是某个更大总体上。这正是作者说的目标试验人群（target trial population）——第 4 章讨论的可迁移性（transportability）问题正是在问：当你想把效应外推到另一个地区、另一种年龄结构的人群时，该换掉的是哪一个分布。另外，三区块的写法在 SAS/R 里就是 expand 之后"预测—取平均"的那套路子，Stata 里对应 expand 3, ... 加 predict；也有等价写法是 stset，或直接用 margins 类命令求预测值的均值。读国内代码时若看到某处把 Pr[L] 换成了外部权重（比如某地区的人口年龄构成），那就是从"研究人群"换到了"目标人群"，两者不是一回事。

在更贴近现实的例子（比如我们这个 L 维度很高的戒烟研究）中，用经验分布做标准化才是正路。做法与上面针对表 2.2 数据描述的完全类似：给数据集加上第二、三块，按上一节所述拟合 E[Y|A = a, C = 0, L = l] 的回归模型，然后生成预测值。第二区块预测值的平均——即未处理组的标准化平均——为 1.66；第三区块预测值的平均——即处理组的标准化平均——为 5.18。

13.4 IP 加权还是标准化？

到现在我们讲了两条用建模来估计处理平均因果效应的路径：IP 加权（上一章）与标准化（本章）。在戒烟这个例子里，两者给出的效应估计几乎完全相同。技术要点 2.3 已经证明标准化平均等于 IP 加权平均。

既然如此，既然上一章已经算过 IP 加权平均，这一章为什么还要费劲去估标准化平均？答案是：只有在完全不使用模型的情况下，IP 加权平均与标准化平均才精确相等；一旦用了模型，两者就有差别了。看看实现这两条路径各自需要建模的量就清楚了。IP 加权要建模的是 Pr[A = a, C = 0|L]，上一章我们分别对 Pr[A = a|L] 和 Pr[C = 0|A = a, L] 拟合参数化 logistic 回归来估计它。标准化要建模的是条件均值 E[Y|A = a, C = 0, L = l]，本章我们用一个参数化线性回归模型来估计它。

实践中，所有模型都在某种程度上被错误设定（misspecification）是在所难免的，而模型误设会引入偏倚。但处理模型（IP 加权）的误设与结局模型（标准化）的误设，一般不会在效应估计中产生量级和方向都相同的偏倚。因此，不可避免的模型误设会以不同方式影响两个点估计，IP 加权估计与标准化估计自然就会不同。两者差距很大，就提醒我们至少有一个估计存在严重的模型误设。差距小虽不能保证没有严重误设，但多少让人安心——虽然从逻辑上说这是可能的，两个模型都误设得同样厉害、偏倚又同量级同方向的可能性毕竟不大。

在戒烟这个例子里，IP 加权估计与标准化估计很接近。四舍五入到小数点后一位，无论我们是为处理 A 建模（IP 加权）还是为结局 Y 建模（标准化），戒烟带来的体重增加都是 3.5 kg。两种情形下我们都没有为混杂因素 L 建模：IP 加权估计不需要 L 的分布，标准化估计则可以用 L 的经验分布（非参数方法）算出来。

IP 加权与标准化都是 g 算法的估计量——g 算法是一种一般性的因果推断方法，最早见于 1986 年（第三部分给出了 g 算法在时变处理情境下的定义）。我们说标准化是一个 plug-in（代入式）的 g 算法估计量，因为它干脆把 g 算法中的条件均值结局替换成它的估计值。当这些估计值像本章这样来自参数模型时，我们就把这个方法称为参数化 g 算法（parametric g-formula）。由于这里我们只关心平均因果效应，所以参数化估计的只是条件均值结局。

译注

译注 4（IP 加权 vs 标准化：这个取舍在国内教材里几乎没人系统讲）：中文的流行病学与医学统计教材在讲观察性研究的数据分析方法时，处理混杂的常规配方基本只有"分层"和"多元 logistic 回归调整"，真正把 IP 加权与标准化并列、并指出两者可识别性条件相同而建模对象不同的教材极少。作者在 13.4 节讲的判据值得抄下来当检查清单：看你要估计的量需要建模哪一个对象——要 Pr[A|L] 就走 IP 加权，要 E[Y|A,L] 就走标准化，两者都不放心就用双重稳健。这个逻辑在中文语境里更有现实意义：医保数据库研究（各地统筹结算数据）里混杂因素往往几十上百个且高度非线性，正态性较好的结局（住院天数、费用、血压值）用倾向性评分加权，在中文文献中已经相当普及；但同一批数据若结局是二值的（住院、死亡、再入院），多数论文仍然只报 logistic 回归的调整后 OR，而不报标准化风险差。这既有方法学上的原因，也有期刊与读者对"调整后 OR"这种形式的路径依赖。

更一般地说，若要估计结局概率密度函数（pdf）的参数化 g 算法，就需要估计给定 A 与 L 各水平下结局的条件分布，才能算出它的标准化取值。在不存在时变混杂因素的情况下（见第三部分），参数化 g 算法并不要求对混杂因素的分布作参数化建模。

Robins（1986）把标准化推广到时变处理和时变混杂因素，把它命名为 g 计算算法公式（g-computation algorithm formula）。这个名字太长，不少作者缩写为 g-formula，另一些写作 g-computation。尽管 g-formula 与 g-computation 是同义词，本书只用前者，因为后者常常与 g 估计（g-estimation，第 14 章所述的另一种方法）混淆。

很多时候根本不必在 IP 加权与参数化 g 算法之间二选一。当两种方法都能用来估计因果效应时，两个都用。另外，只要可能，就用双重稳健（doubly robust）方法，把处理模型与结局模型并入同一个估计量。在给定 L 的可交换性与可阳性性之下，只要处理模型或结局模型其中一个是对的，双重稳健估计量就能一致地估计平均因果效应，而且不必事先知道是哪一个对。双重稳健估计量中有一个具体形式叫双重稳健 plug-in 估计量，见精细辨析 13.2；另一个叫增广 IP 加权估计量，见技术要点 13.2；两者之间的数学关系见技术要点 13.3。

最后注意，我们是用参数化 g 算法来估计目标人群整体上的平均因果效应的。若我们只关心某个子人群中的平均因果效应，把计算限制在那个子集里就行。举例来说，若我们想考察性别是否构成潜在的效应修饰，就可以分别在男性和女性中各估一个标准化平均。IP 加权与参数化 g 算法都能估计整个人群或某个子人群中的平均因果效应。

技术要点 13.1　Bootstrap（自助法）

第 10 章我们讨论过因果效应随机变异的根基。效应估计必须配上变异度量，比如标准误（或标准误的函数，如 95% 置信区间）。由于精确估计难以计算，实践中的标准误估计往往依赖大样本近似，而大样本近似又依赖渐近理论。但有时候，连大样本近似都嫌太复杂，算不动。

bootstrap 是估计标准误、计算 95% 置信区间的另一条路。下面勾勒它最简单的版本——非参数 bootstrap——我们在正文里就是用它算出戒烟效应估计的 95% 置信区间的。

取那 1629 人的研究人群作为抽样总体。有放回地抽出 1629 人，于是有些原个体可能被抽到多次，另一些则一次也没被抽到。这个规模仍为 1629 的新样本称为一个"bootstrap 样本"。在这个 bootstrap 样本上计算所关心的效应（例如用正文所述的标准化）。然后再造一个 bootstrap 样本，同样有放回地抽 1629 人，用与第一个完全相同的方法算效应。纯属偶然，第一个与第二个 bootstrap 样本中每个个体被抽到的份数一般不同，因而算出的效应估计也不同。把这个过程重复很多次（比如 1000 次）。结果是：这 1000 个 bootstrap 效应估计的标准差，能够一致地估计研究人群中效应估计的标准误。95% 置信区间随后按惯常的正态近似算出：估计值 ± 1.96 倍标准误估计。bootstrap 背后的统计理论，可参见 Wasserman（2004）。

我们用了 1000 个 bootstrap 样本，得到正文里标准化平均差的那个 95% 置信区间。bootstrap 是一种通用的多样本方法：一般地，当估计量的极限分布为正态时，以估计量为中心、标准误由非参数 bootstrap 估出的 95% Wald 置信区间在大样本下是校准良好的。因此，边际结构模型（marginal structural model）的 IP 加权估计，若标准误用 bootstrap 估计，其 95% Wald 置信区间是校准的；而若用前面讲过的稳健方差估计量（取平方根）来估，往往会偏保守、偏宽。

非参数 bootstrap 虽然简单，在超大数据集上却可能算得很费时间。所以发表的估计里，只用了 200–500 个 bootstrap 样本的并不少见。在我们的例子里，这样砍一刀得到的置信区间几乎与原来一样，但并非总是如此。兼顾计算量与 bootstrap 优点的更好办法，是 Kleiner 等人（2014）提出的巧妙做法——"一袋小 bootstrap"（bag of little bootstraps）。

精细辨析 13.2　双重稳健的 plug-in 估计量

上一章介绍的 IP 加权，要求关于处理 A 相对于混杂因素 L 的模型是正确的。本章介绍的标准化，要求关于结局 Y 相对于处理 A 与混杂因素 L 的模型是正确的。那有没有一种方法，只要求处理 A 或结局 Y 有一个模型正确就够了？这正是双重稳健估计所做的事。在通常的可识别性假设下，只要两个模型中至少有一个正确（而且你不必知道是哪一个正确），双重稳健估计量就能一致地估计因果效应。也就是说，双重稳健估计量给了我们两次猜对的机会。

双重稳健估计量有很多种。这里介绍一种（Bang 与 Robins，2005），用于估计二值处理 A 对结局 Y 的平均因果效应。为简单起见，我们考虑没有删失的情形。

要对平均因果效应做双重稳健估计，先按上一章的做法估出 IP 权重 WA = 1/f(A|L)。然后拟合一个像本章所述的结局回归模型——一个带典范连接函数（canonical link）的广义线性模型——去估计 E[Y|A, L, R]，其中额外加入协变量 R，而 R = WA（当 A = 1）或 R = −WA（当 A = 0）。最后，用结局模型在把每个人的 A 都设为 1 时得到的预测值，算出 A = 1 下标准化平均结局的估计；再把 A 都设为 0 重做一遍，得到 A = 0 下标准化平均结局的估计。两个估计量之差，就是平均因果效应的双重稳健 plug-in 估计量。

技术要点 13.2　增广 IP 加权估计量（augmented IP weighted estimator）

设我们有二值处理 A、结局 Y，以及一组满足可阳性性与可交换性的已测变量 L（一致性默认成立）。为简单起见，我们考虑估计处理下的反事实均值 E[Ya=1] 而非因果效应。E[Ya=1] 既可写成 E[b̂(L)]（其中 b(L) = E[Y|A = 1, L]），也可写成 E[π(L)AY/π(L)]（其中 π(L) = Pr[A = 1|L]）。本章我们描述的 plug-in g 算法估计量 (1/n)∑i=1n b̂(Li)，是用一个（比如线性的）参数回归模型估计 b(L) 再在全部 n 个个体上取平均。上一章我们描述的 Horvitz–Thompson IP 加权估计量 (1/n)∑i=1n AiYi/π̂(Li)，则是用一个（比如 logistic 的）参数回归模型估计 π(L) 再在 n 个个体上取平均。若 b̂(L) 离 b(L) 很远，plug-in g 算法估计量的偏倚就大；若 π̂(L) 离 π(L) 很远，IP 加权估计量的偏倚就大。

E[Ya=1] 的一个双重稳健估计量，会恰当地把结局模型给出的 b̂(L) 与处理模型给出的 π̂(L) 组合起来。双重稳健估计量有很多形式，精细辨析 13.2 描述的只是其中一种。所有双重稳健估计量都用某个涉及处理模型的函数去修正结局回归模型；换个角度看，也都是用某个涉及结局回归模型的函数去修正 Horvitz–Thompson 估计量。例如，考虑下面这个 E[Ya=1] 的双重稳健估计量：

Ê[Ya=1]DR = (1/n) ∑i=1n [ b̂(Li) + (Ai/π̂(Li)) (Yi − b̂(Li)) ]

它也可以写成 (1/n)∑i=1n [ AiYi/π̂(Li) − (Ai/π̂(Li) − 1) b̂(Li) ]。受后一个公式启发，人们把 Ê[Ya=1]DR 称为增广 IP 加权估计量（augmented IP weighted estimator）。

在可交换性与可阳性性之下，只要 b̂(L) 接近 b(L)，或者 π̂(L) 接近 π(L)，这个双重稳健估计量的偏倚就小。具体地说，E[Ê[Ya=1]DR] − E[Ya=1] 会依概率收敛到 E[ (1/π(L))(1/π*(L) − 1)(b(L) − b*(L)) ]，其中 π*(l) 与 b*(l) 分别是 π̂(l) 与 b̂(l) 的概率极限。由此可知，当参数化结局模型正确（b*(l) = b(l)）或参数化处理模型正确（π*(l) = π(l)）时，我们的双重稳健估计量（渐近地）无偏。而且，我们不需要知道两个模型中究竟是哪一个正确。当然，若向量 L 维度极高，本来就不指望任何参数模型能被正确设定，这时即便双重稳健估计量的偏倚也可能很大。

不过，所有双重稳健估计量都有这么一条性质：其偏倚取决于估计 π(l) 时 1/π(l) − 1/π̂(l) 这一误差，与估计 b(l) 时 b(l) − b̂(l) 这一误差的乘积。正如第 18 章将讨论的，这个性质被称为二阶偏倚（second-order bias）；借助它，我们可以用机器学习估计量而不是标准参数模型来估计 π(l) 与 b(l)，从而构造出偏倚可能很小的双重稳健估计量。原因是，在数据量充足的高维场景中，基于复杂算法的机器学习估计量对 π(l) 和 b(l) 给出的估计，比标准参数模型更准确。

技术要点 13.3　增广 IP 加权估计量与双重稳健 plug-in 估计量的关系

再看一遍反事实均值 E[Ya] ≡ ψa，并假定可识别性条件成立。则 ψa = E[b(a, L)]，其中 b(a, L) = E[Y|A = a, L]；同时 ψa = E[I(A = a)Y/f(a|L)]。如技术要点 13.2 所述，反事实均值 E[Ya] ≡ ψa 的增广 IP 加权（AIPW）估计量 ψ̂a,AIPW 为

ψ̂a,AIPW = (1/n)∑i=1n [ I(Ai = a)Yi/f̂(a|Li) − (I(Ai = a)/f̂(a|Li) − 1) b̂(a, Li) ]
= (1/n)∑i=1n [ b̂(a, Li) + I(Ai = a)(Yi − b̂(Ai, Li))/f̂(Ai|Li) ]

其中对任意 H 有 Pn[H] ≡ (1/n)∑i=1n Hi，f̂(a|L) 与 b̂(a, L) 分别是 f(a|L) 与 b(a, L) 的估计量（Robins 等，1994；Robins 与 Ritov，1997）。该估计量之所以是双重稳健的，是因为：(i) 若 f̂(a|L) 一致，则上式左端依概率收敛到 ψa = E[I(A = a)Y/f(a|L)]；(ii) 若 b̂(a, L) 一致，则上式右端收敛到 ψa = E[b(a, L)]。由此，平均因果效应 E[Y1] − E[Y0] = ψ1 − ψ0 的 AIPW 估计量 ψ̂1,AIPW − ψ̂0,AIPW 也是双重稳健的：只要 (i) f̂(a=1|L) = 1 − f̂(a=0|L) 一致，或 (ii) b̂(1, L) 与 b̂(0, L) 都一致，它就是一致的。

现在有了双重稳健的 AIPW 估计量，怎么从中得到精细辨析 13.2 的双重稳健 plug-in 估计量？从上式右端可以看出 ψ̂1,AIPW − ψ̂0,AIPW = Pn[b̂(1, L) − b̂(0, L)] − Pn[{Y − b̂(A, L)}/f̂(A|L) {I(A = 1) − I(A = 0)}]。如果我们想要一个双重稳健的 plug-in 估计量 Pn[b̂(1, L) − b̂(0, L)]，就需要在每一个样本里都满足

Pn[ {Y − b̂(A, L)}/f̂(A|L) {I(A = 1) − I(A = 0)} ] = 0

只要取 b̂(A, L) = b(A, L; β̂, θ̂)，其中 θ̂ 是模型 E[Y|A, L] = b(A, L; β, θ) = ϕm(A, L; β) + θ {I(A=1) − I(A=0)}{Y − b̂(A,L)}/f̂(A|L) 的迭代重加权最小二乘（IRLS）估计，上述等式就成立，ϕ 是某个典范连接函数（如 log、logit 或线性连接）的逆函数。原因是，上面那个等式正是模型中参数 θ 所对应的得分方程（Robins 1999；Bang 与 Robins 2005；Scharfstein 等 1999）。由此得到的 plug-in 估计量，正是精细辨析 13.2 的那个估计量。它是一个定向最小损失估计量（targeted minimum loss-based estimator，TMLE），也叫定向极大似然估计量（targeted maximum likelihood estimator），而 {I(A=1) − I(A=0)}{Y − b̂(A,L)}/f̂(A|L) = π̂(|L)A − (1 − A)(1 − π̂(|L)) 在 van der Laan 与 Rubin（2006）后来引入的术语里称作"巧协变量"（clever covariate）。

能使上述等式成立的模型不止一种选择。例如，可以把上述模型中的 θ 项换成 θ1π̂(|L)A + θ2(1 − A)(1 − π̂(|L))，并同时估计 θ1 与 θ2（Scharfstein 等，1999；Bang 与 Robins，2005）。后一个估计量同样是 TMLE，但此时有两个巧协变量：π̂(|L)A 与 (1 − A)(1 − π̂(|L))。双巧协变量模型相对于单巧协变量模型的一个优点是：此时 Pn[b̂(1, L)] 与 Pn[b̂(0, L)] 本身也分别是 E[Ya=1] 与 E[Ya=0] 的双重稳健 plug-in 估计量，而 Pn[b̂(1, L) − b̂(0, L)] 仍是平均处理效应的双重稳健估计量。

13.5 我们该多认真地对待自己的估计？

本书第一部分，我们回顾了平均因果效应的定义、估计它所需的假设，以及各种潜在的偏倚。那番讨论纯属概念层面的，数据例子也被简化到了极点。其中一个核心信息是：明确地去模拟一个（假想的）随机试验——即目标试验——能让观察性数据的因果分析更锋利。

本章和上一章的分析，是我们头一次尝试从真实数据中估计因果效应。用 IP 加权和参数化 g 算法我们都算出：若所有人都戒烟，平均体重增长本会是 5.2 kg；若无人戒烟，则为 1.7 kg。两种方法都给出戒烟平均使体重增加 3.5 kg（95% 置信区间：2.5, 4.5）。在接下来的几章里我们会看到，用 g 估计、结局回归与倾向性评分也能得到相近的估计。

不同方法所得估计彼此相容，这让人安心，因为每个方法的估计各自建立在不同的建模假设之上。然而，观察性效应估计永远是任人批评的对象。即便我们不打算把效应估计外推到其他人群（第 4 章），即便个体之间不存在干扰，我们对目标人群的估计要站得住脚，仍然需要许多条件。我们把这些条件归为三组。

第一，可交换性、可阳性性与一致性（第 3 章）这些可识别性条件必须成立，观察性研究才能与目标试验相似。戒烟者与不戒烟者需要在 9 个已测协变量 L 的条件下可交换（见精细辨析 14.2）。未测混杂（第 7 章）或选择偏倚（第 8 章，精细辨析 12.2）都会破坏条件可交换性。可阳性性则要求混杂因素 L 在戒烟者中的分布，与在不戒烟者中的分布完全重叠；精细辨析 13.1 讨论过可阳性性被违背时，对非参数 IP 加权与标准化影响有何不同。至于一致性，要注意到戒烟（渐进戒、断然戒）与不戒烟（每天多抽 2 支、减量但不归零）都各有多个版本。我们这份效应估计对应的是目标人群里一个含义相当含糊的假想干预：按这些版本在研究人群中实际出现的频率，把它们随机分配出去。换一组别的假想干预，效应估计可能就不一样。这一"数值估计依赖于具体干预定义"的特点，在用估计指导公共卫生政策或临床决策时格外要紧（Hernán 2016）。

第二，分析中用到的所有变量都必须被正确测量。处理 A、结局 Y 或混杂因素 L 上的测量误差一般都会导致偏倚（第 9 章）。实践中，多数变量有某种程度的测量误差是在所难免的。

第三，分析中用到的所有模型都必须被正确设定（第 11 章）。设想年龄这个连续协变量在处理模型中的正确函数形式并不是我们用的抛物线，而是一条由复杂多项式表示的曲线。那么，即便所有混杂因素都被正确测量并纳入了 L，IP 加权也无法充分调整混杂。模型误设造成的后果，与混杂因素上的测量误差类似。

我们这项因果推断的有效性，需要下列条件：

  • 可交换性
  • 可阳性性
  • 一致性
  • 无测量误差
  • 无模型误设

设法让上述每一项条件都（至少近似）成立，是研究者最重要的任务。假如这些条件能被保证成立，数据分析就是一件轻松的事。问题在于，谁也不能指望其中任何一项会完美成立。未测的混杂因素、混杂因素分布不重叠、干预定义不清、变量测错、模型设定错误——这些东西通常就潜伏在我们估计值的背后。其中一部分可以通过经验途径处理，另一些则仍然是专业判断问题，因而会招致数据本身无法反驳的批评。比如，我们可以提出不同的模型设定，可那些压根没被测量的变量，我们是无从调整的。

上面报告的效应估计，只有在所有这些（英雄般的）条件都成立时，才是戒烟平均因果效应的无偏估计。我们的研究与这些条件偏离得越多，效应估计的偏倚就可能越大。这些条件无法用经验数据检验，因为我们手上没有反事实结局分布的数据。因此在实践中，我们只能假定上述条件大致成立；而这一假定需要专家知识来支撑，正如 7.6 节在讨论因混杂导致不可交换性时所做的那样。

可专家知识本身是不完整的。结果是，现有的专家知识通常与一整片条件范围都相容：从几乎完美的可交换性（因为所有已知的混杂因素都未被测量）一直到中度不可交换（因为也许还有我们不晓得的混杂因素）。因此在实践中，我们需要在不同假设下分别做分析，看看效应估计对最初那些假定的敏感程度如何。本书针对混杂的敏感性分析（见精细辨析 7.1 中列出的文献）通过阴性对照结局（技术要点 7.5）与 g 估计（精细辨析 14.2）来进行，针对选择偏倚的敏感性分析见精细辨析 12.1，针对模型误设的敏感性分析见 11.5 节。效应估计对我们所依赖的那些无法验证的条件的敏感度，还可以通过定量偏倚分析（精细辨析 10.2）来考察，或者有时改用另一些无法验证的条件——例如工具变量估计所需的条件（见第 16 章）。理想的情形是，每个因果推断研究项目都把敏感性分析纳入其中。

在存在未测混杂的情况下，另有一组可识别性条件离我们更近：近端因果推断（proximal causal inference，见技术要点 7.3）与前门准则（front door criterion，见技术要点 7.4）。

对从观察性数据得出的因果推断保持一点健康的怀疑，是必要的。但要让它有建设性，这种怀疑就得扎根于关于假设有效性的专家知识。让因果推断变得更不随意的一个关键步骤，是认识到讨论应当主要围绕上面那一条条假设展开。我们对自己估计的认真程度，至多只能等于我们对"使这些估计获得因果解释所需条件"的认真程度。

译注

译注 5（存在未测混杂时的替代方案）：当混杂无法通过测量更多变量来解决时，另一套思路是不靠可交换性，而是换一组可识别性条件——近端因果推断（proximal causal inference，Miao、Tchetgen Tchetgen 与 Geng 等，见技术要点 7.3）与前门准则（front door criterion，Pearl 提出，见技术要点 7.4）。前门准则要求找到一组既影响混杂因素、又能独立于混杂因素影响结局的中介变量，这在中国的场景里并不罕见：比如研究"吸烟对某疾病的影响"时，族群身份可充当前门；更常被拿来举例的是医保场景下的"参保行为"——参保既由健康状况与收入（混杂因素）决定，又通过就医行为影响结局，这几乎是教科书式的应用。相比之下，国内目前对近端因果推断的系统应用还很少，相关论文屈指可数，方法学上值得中文读者关注。

译注

译注 6（"边际效应"与"条件效应"为什么对不上：noncollapsibility）：作者在本章反复强调"换哪一个模型"会给出不同的点估计，这对中文读者熟悉的一个现象是很好的解释：不可塌缩性（noncollapsibility，Pearl 在讨论 GEE 与 logistic 回归之争时提出）。同一批数据，logistic 回归给出的调整后 OR 为 2.0，而 Mantel–Haenszel 分层估计的合并 OR 却是 1.6；同样，回归调整后的边际风险差与"把各层直接按混杂分布加权平均"得到的风险差也不相等。原因是 odds 比（以及任何比值尺度上的比值）在按其他变量分层或调整时并不保持不变——即使那个变量与处理、结局都无关，因为它把四个格子的概率往内部挤，ad/(ad+bc) 也会变。相比之下，风险差是可塌缩的（collapsible）：本章的标准化平均正是风险差这一族的量，所以它天然等于"各层条件均值按 L 的分布加权平均"。这才是 13.4 节强调"IP 加权估计与标准化估计可以互相印证"的根本原因。国内医学期刊上"调整后 OR 与分层分析结果不一致"引发的反复讨论，多半是这条性质在作祟，并不是谁算错了。

译注

译注 7（可阳性性的现实麻烦，兼谈 TMLE 在中国的落地）：精细辨析 13.1 讲的"结构性可阳性性"在真实数据里很常见。国内医保结算数据的典型例子是：某药只在三级医院或某些特定科室使用，于是"住院天数"这个混杂因素在用药组与未用药组中几乎不重叠，Pr[A=1|L] 在一整片区域精确为 0。此时倾向性评分模型会外推出天文数字般的权重，而标准化（若结局模型正确）反而还能给出可解释的答案——这正是作者说的"标准化可以靠参数外推硬扛"。这大概也是近年来国外流行病学界转向 TMLE 的原因之一：TMLE 不强加参数模型，而是在模型不够好时把估计"定向"到满足某个特定的得分方程，同时保留双重稳健性质（技术要点 13.3 的数学就是这件事）。国内已有团队在医保与电子病历数据上实现 TMLE 并用于慢病与死亡风险的估计，但面向临床研究者的中文教程仍相当稀缺；不少中文论文所谓"用机器学习做因果推断"，实际做的只是把倾向性评分交给随机森林或 XGBoost——那只解决了处理模型一侧，尚未触碰二阶偏倚这条主线。

译注

译注 8（bootstrap 与中文文献里的 CI 习惯）：技术要点 13.1 介绍的一千次重抽样，是因果推断领域近十年已成标准的报 CI 方式，但国内临床与流行病学论文里仍大量沿用 1990 年代的做法：只报 Wald 区间，或用 sandwich 稳健方差，或干脆把 logistic 回归输出里的 95% CI 直接抄下来。放在 IP 加权或标准化这类加权估计量上，稳健方差往往偏保守（正如本节所说），报出来的区间会比真区间宽上一截，看起来倒更"安全"。反过来，若研究用了 TMLE 或目标试验模拟（target trial emulation，Hernán 与 Robins 在 2016 年后大力推动的方法范式），报 CI 的标准做法就是 bootstrap。国内读者若看到文献只用一个模型（且不报权重分布、不报混杂平衡诊断），可以先追问一句：换用第二个模型会得到什么？——这正是 13.4 节给出的那条最容易上手的检查。
