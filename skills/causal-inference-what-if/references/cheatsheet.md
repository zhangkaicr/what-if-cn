# 决策规则速查 — Causal Inference - What If

| 能力 | 一句话规则 |
|---|---|
| 目标试验模拟：先写试验方案，再碰数据 | 拿到观察性数据先别建模，先把'我本来想做的那个随机试验'的 7 项方案写出来。 |
| 因果图识别与后门准则 | 把假设画成箭头，再用后门准则挑调整集合——调整不该靠'把所有变量都塞进模型'。 |
| 偏倚的结构化分类：按图的结构认偏倚，不按名字认偏倚 | 混杂 = 共同原因；选择偏倚 = 条件于共同结果；测量偏倚 = 变量测错了或测的是代理。 |
| 选择偏倚与永恒时间偏倚：时间零点一错，全盘皆错 | 入组、治疗分配、随访开始必须落在同一时刻；只要它们错开，就有人必须先活够一段时间才'配'被治疗。 |
| 标准化与 g-formula：把结局模型铺到整个人群上 | 给每个人预测'若治疗'和'若不治疗'两个结局，再对全人群各求一次平均，两个平均相减。 |
| IP 加权与边际结构模型：造一个治疗与混杂无关的人群 | 给每个人加一个权重 1/P(A|L)，造出一个'治疗与混杂无关'的伪人群，再在里面比较结局。 |
| 时变处理的 G 方法：当治疗会改变它自己的混杂因子 | 一旦治疗会改变日后的混杂因子，传统回归无论怎么调整都有偏——只能用 g-formula、IP 加权或 G-estimation。 |
| 可识别性三条件：可交换性、正值性、一致性 | 数据能回答因果问题，当且仅当：可交换、正值、且干预定义明确（一致性）。 |
| G-estimation 与结构嵌套模型：直接给效应建模 | 不去建治疗或结局的模型，而是直接给'效应'建一个模型，再搜索让治疗与反事实独立的那个参数值。 |
| 双重稳健估计：两个模型，对一个就够 | 同时建结局模型和治疗模型，只要其中一个是正确的，估计就一致——但不是两个都错也无所谓。 |
| 工具变量估计：当可交换性没法假设时 | 三个条件（相关性、排除限制、独立性）之外，还必须有第四个：同质性或单调性——否则估出来的东西没有因果解释。 |
| 效应修饰与交互：两个常被混为一谈的概念 | 效应修饰：效应大小随某变量变（换尺度就可能消失，不是「交互」）；交互：两个干预必须联合施加才能谈。 |
| 因果中介分析：在「调整中介」之前先问能不能干预它 | 中介分析的前提是中介变量可被干预；只有当「把中介固定在某值」是一个可执行操作时，直接/间接效应才有因果意义。 |
| 因果推断中的变量选择：目标不是预测结局 | 选变量不看「能不能预测结局」，而看它在 DAG 上的位置——调整对撞节点和强工具变量会主动放大偏倚。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
